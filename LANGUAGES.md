# Contributing translations to GravesX

1. Copy `src/main/resources/config/language/en-US.yml` to a new locale file, for example `fr-FR.yml` or `es-ES.yml`.
2. Translate values only. Keep `message.*` keys, YAML structure, formatting codes, and placeholders (such as `%owner_name%` and `%world_formatted%`) intact.
3. Submit the new locale file as a pull request.
